# Technical Artefacts

This directory contains supporting technical artefacts produced during the development, experimentation, implementation and testing of the NLP-Based Phishing and Social Engineering Email Detection project.

The artefacts document model experimentation, the DeBERTa-v3-large phishing-detection implementation, Streamlit-based testing, browser-extension integration, explainable AI and end-to-end email testing.

Associated source code is maintained in the corresponding implementation directories of this repository.
