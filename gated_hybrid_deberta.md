# Gated Hybrid DeBERTa Model

## Overview

Following the development and evaluation of the DeBERTa-v3-large model, an enhanced hybrid architecture was investigated to determine whether additional engineered NLP and security-related features could improve phishing email classification.

The proposed architecture combines contextual representations generated by DeBERTa-v3-large with twelve engineered features through a learnable gating mechanism.

## Architecture

The hybrid model consists of the following stages:

Email Text
→ DeBERTa-v3-large
→ Contextual Representation
→ Context Projection

Engineered NLP/Security Features
→ Feature Projection

Context Projection + Feature Projection
→ Learnable Gate
→ Feature Fusion
→ Classification Layer
→ Safe / Phishing

## Engineered Features

The twelve additional features used by the model were:

1. Urgency-word frequency
2. Credential-related terms
3. Threat-related terms
4. Financial terms
5. Call-to-action terms
6. URL count
7. Email-address count
8. Phone-number count
9. Exclamation-mark count
10. Question-mark count
11. Uppercase-word ratio
12. Logarithmic text length

The features were normalised using statistics derived from the training data.

## Gated Fusion

A learnable gate was introduced to control the contribution of the engineered features relative to the contextual representation generated by DeBERTa-v3-large.

This design was investigated to determine whether explicit phishing-related linguistic and security indicators could complement the contextual information learned by the transformer.

## Test Results

| Metric | Standard DeBERTa-v3-large | Gated Hybrid DeBERTa |
|---|---:|---:|
| Accuracy | 99.3721% | 99.3721% |
| Precision | 98.9346% | 99.2343% |
| Recall | 99.3884% | 99.0826% |
| F1-score | 99.1609% | 99.1584% |
| Test Loss | 0.04341 | 0.02648 |
| False Positives | 7 | 5 |
| False Negatives | 4 | 6 |

## Evaluation

The hybrid architecture did not improve the overall accuracy or F1-score compared with the standard DeBERTa-v3-large model.

However, it produced higher precision and fewer false positives, while the standard DeBERTa-v3-large model achieved higher recall and fewer false negatives.

This experiment therefore provided a useful architectural comparison rather than demonstrating that the hybrid approach was universally superior.

## Outcome

The experiment demonstrated that engineered phishing-related features could be incorporated with transformer representations through a gated fusion architecture.

The results were used as part of the project's model refinement and evaluation process and contributed to the subsequent development of the integrated phishing detection system.
